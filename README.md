## 🚩 Project Overview

**CLAUDCANVAS** is designed to democratize media editing. You don't need to be a professional video editor, graphic designer, or software engineer to create stunning visual content. By combining an ultra-intuitive user interface with enterprise-grade AI tools, CLAUDCANVAS allows anyone to drop, transform, and manage media files in seconds. 

---

## ☁️ Powered by Cloudinary AI: Built for Everyday Creators

At the core of CLAUDCANVAS is the robust **Cloudinary AI Toolkit**. Instead of dealing with complex desktop software, non-techie users can harness advanced cloud-based AI directly through their browser:
* **Zero Technical Friction:** No coding, no command lines, and no heavy software installations required.
* **Instant Automation:** Cloudinary’s intelligent generative AI handles heavy lifting like background isolation, object removal, and video compression automatically behind the scenes.
* **Lightning-Fast Delivery:** Optimized asset delivery ensures your transformed media loads instantly anywhere.

  <img src="https://skillicons.dev/icons?i=nextjs,react,tailwind,python,django,postgres,git,github,vercel&theme=dark" />

* **Frontend:** Next.js (App Router), Tailwind CSS — Clean, accessible modern UI
* **Backend API:** Python, Django REST Framework (DRF) — Secure transformation handlers
* **Cloud Infrastructure & AI:** Cloudinary Generative AI API
* **Database:** Neon Database — Serverless PostgreSQL
* **Payments:** Stripe Checkout Integration
